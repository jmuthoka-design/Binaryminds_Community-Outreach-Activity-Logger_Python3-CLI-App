# Sources & AI Disclosure

Claude (Sonnet), an AI assistant made by Anthropic, was used as a
learning aid during the planning and building of this project.

## How AI Was Used

- Discussing and refining the idea for the Community Outreach
  Activity Logger, including deciding on the data fields to store
  and the difference between Organization and Individual users.
- Getting an explanation of how to structure a Python project into
  separate modules (main.py, validation.py, data_store.py,
  records.py, processing.py).
- Getting help writing and simplifying the Python code so that it
  uses only beginner-level concepts (loops, if/else, functions,
  lists, dictionaries, try/except) without more advanced shortcuts,
  so that it could be explained clearly in class.
- Getting help drafting this Requirements Note and the README.md
  file.
